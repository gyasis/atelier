Atelier

One Mac Studio. Every medium.

A household AI compute box that hosts text, audio, image, and video inference as a fleet of uniform Python sidecars — so any client on the network hits one HTTP endpoint per workload instead of running models in-browser. Atelier is French for workshop.

System overview · 2026-05-25
01

The thesis

Centralize every model on the box that has the memory. Keep clients thin. The network is the API.

Running models in-browser or re-downloading weights per app wastes the one scarce resource on this hardware: unified memory. Atelier is deliberately two things at once — a production engine the githubawesome podcast depends on daily, and an experimentation platform: "a bigger ComfyUI for all media models," where a new TTS, image, or video model slots in behind the same contract and gets A/B-compared.

The defining constraint

Apple Silicon has no hard OOM like CUDA. Exceed ~55 GB resident and macOS silently pages to NVMe — a 5-minute render becomes a 2-hour hang with no error. Memory contention, not disk or compute, is the ceiling. Every design decision below exists to respect it.

05

The sidecar contract

Every workload is a small FastAPI app following one shape.

HTTP

Uniform surface

/healthz · /readyz · /tts · /admin/unload. One inference at a time — asyncio.Semaphore(1) single-flight.

RUNTIME

uv + Metal

A uv venv (Python 3.12) per sidecar. PyTorch on MPS, or ONNX/CoreML, or MLX — whatever the engine needs.

MEMORY

Idle-unload economy

Server stays up; the model unloads after IDLE_UNLOAD_SECONDS and frees the memory. Don't fill 64 GB with idle trash.

LAUNCHD

Managed service

RunAtLoad + KeepAlive, wrapped in caffeinate -i (defeats App Nap), with MPS-fallback env in the plist.

Operating the hub

deploy/install.sh

Fresh-Mac bootstrap — venvs, pinned deps, symlink sidecars, copy plists, fetch models, launchctl bootstrap every service.

deploy/doctor.sh

Audit: every sidecar has a plist, every plist is installed + loaded + healthy. Exit 1 on any gap — born from the reboot that killed the un-codified OmniVoice.

atelier-status

Live health of all sidecars — state, idle seconds, device — plus --unload <name> for manual memory eviction.

08

The ambitions

Every medium under one contract

Text, audio (TTS + ASR), image, video, embeddings — each a uniform sidecar, each hot-swappable.

Production + experimentation in one box

Ship a single production engine per medium; keep the bench open to A/B a new model the moment it lands.

Memory-economy as a first principle

Idle models unload; nothing hoards the 64 GB it isn't using. TTS + a video render + an LLM, without touching swap.

Reproducible from zero

install.sh rebuilds the whole hub on a fresh Mac; doctor.sh proves it's whole. No model lives outside the repo's knowledge again.
